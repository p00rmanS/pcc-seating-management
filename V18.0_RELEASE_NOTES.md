# Meʻa Hoʻokipa Dining Operations v18.0

## Platform Workspace Update

v18.0 separates the seating editor and daily operations into distinct workspaces.

### New platform navigation
- Seating
- Operations
- Training (reserved for a future release)
- Reports (reserved for a future release)

### Operations workspace
- Full-width dedicated page instead of a cramped sidebar
- Venue and date controls remain visible
- Assignments, cloths, leis, frozen desserts, pax, and history remain available
- Responsive desktop, tablet, and mobile layouts
- Venue tabs continue to switch the active restaurant

### Access behavior
- Management and developer accounts can switch between Seating and Operations
- Operations-only accounts open directly into Operations
- Operations-only accounts cannot return to the editable seating workspace

### Firebase
No new Firebase paths were added beyond the v17.4 operations schema. Complete UI testing before applying the included v17.4 Firebase rules.
