# Meʻa Hoʻokipa Dining Operations v18.2

## Servers Dashboard & Assignment Manager Refinements

Follow-up to v18.1 based on real usage — replaces the account-linked
assignment flow with a lighter, Groups-based workflow that matches how the
team actually tracks who's serving what.

### Servers dashboard
- New toggleable, closable popup (toolbar button: **Servers**) listing every
  name from your existing Groups with live table counts.
- Tap a name to glow their tables gold and dim everything else; tap again to
  clear. Works in the normal desktop view, Full Floor, and Mobile Map.
- No new setup required — it reads the same Groups you already maintain.

### Right-click "Assign to Server"
- The table context menu (right-click a table) now has an **Assign to
  Server** item. Expands in place to a list of your Groups with color dots —
  tap one to assign instantly. Tap "Unassigned" to clear.
- Writes to the same `groupId` the Servers dashboard reads, so assigning a
  table here immediately reflects in the dashboard and glow highlighting.
- Manager/lead only, same permission as Combine/Duplicate/Delete.

### Assignment Manager simplified
- Removed the Firebase-account picker — assignments are free-text names
  again, no linked login required.
- Removed the individual per-table picker (impractical at 60+ tables per
  venue). Areas are now the only table-scoping control — picking an area
  auto-includes every table inside it.
- Kept: copy-yesterday, unassigned/duplicate-table warnings, notes.

### Layout fixes
- Fixed a CSS grid row-count bug: the new "Seating / Operations" module nav
  bar was landing in the workspace grid's flexible content row instead of
  getting its own row, which pushed all remaining content down and left a
  large blank gap above the toolbar/canvas on every venue. Root cause was a
  mismatched `grid-template-rows` track count after the nav bar was added in
  v18.1 — fixed by giving it an explicit row.
- Fixed the module nav also rendering during Full Floor mode, where it
  visually overlapped the occupancy summary widget and floor toolbar.
- Fixed a missing `min-width: 0` on the sidebar/canvas/inspector grid
  columns that could let wide tool-panel content push the whole layout wider
  than the viewport instead of scrolling within its own column.
- Centered and shrank the module nav bar (was right-aligned and oversized).

### Employee login highlighting — status update
The v18.1 "employee logs in and automatically sees their own tables"
behavior (via `staffingAssignments[].employeeUid` matching the logged-in
UID) is now dormant: it depended on linking assignments to real Firebase
accounts, which this release deliberately removes in favor of the simpler
Groups-based flow. The Servers dashboard is the active mechanism going
forward — anyone viewing the seating map, including an employee on their own
device, taps their own name to glow their tables.

### Firebase
No schema changes since v18.1. See `FIREBASE_V18.1_SETUP.md` for the
proposed (not deployed) rules and manual account setup steps — still
accurate for this release.
